# Proto-Petit-et-Gros-cubes
Proto pour la borne d'arcade 2026-2027 - Jeu de coop avec un petit et un gros cube

objectif : attendre la ligne d'arrivé à deux. 

Déroulement : chaque joueur incarne un cube et ils peuvent s'échanger de la masse pour s'entraider. Certains obstacles sont passablent uniquement par un cube petit (ex : passage étroit), d'autres par un gros cube (ex : passage au dessus du vide entre deux barres) et d'autre où les deux cube doivent avoire la même taille (ex : une balance).

Déjà fait :
- mouvement et animation des cubes
- obstacles : balance, poutre équilibrée, murs
- win condition et lose condition
- pages UI de victoir et de défaite
- resawn
